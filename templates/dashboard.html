How to use this view: KEV identifies known exploitation, EPSS estimates exploitation probability, and CVSS describes technical severity. Review these signals together rather than treating any single metric as a complete measure of organizational risk.

Vulnerability Overview — Prioritized for Review

How vulnerabilities are prioritized: The default order is CISA KEV first, then higher EPSS probability, higher CVSS severity, affected asset count, and vulnerability age as a final contextual tie-breaker. A KEV or high-EPSS CVE can therefore appear above a CVSS 9+ CVE that has no known-exploitation signal and a low EPSS probability. CVSS describes potential technical severity; it does not by itself indicate exploitation likelihood. This is a transparent review order, not a proprietary risk score.

Asset Overview — Prioritized for Review

How assets are prioritized: Assets are ordered by number of CISA KEV CVEs, then High EPSS CVEs (≥10%), Critical CVSS findings (≥9.0), highest CVSS, and finally overall CVE/finding exposure. This places systems with known-exploited or higher-likelihood vulnerabilities above systems that merely have a large number of findings. Business criticality, Internet exposure, data classification, production status and other CMDB context are not yet included. This is not a proprietary risk score. Scan Freshness indicates how recently Rapid7 assessed the asset and does not alter priority ranking. Current = <3 days, Aging = 3–10 days, Stale = >10 days, Unknown = no valid scan date.
