HOW IT WORKS

Understanding VulnPrioritizer

VulnPrioritizer supplements traditional vulnerability severity with real-world exploitation intelligence so analysts can understand not only how severe a vulnerability is, but also whether exploitation is predicted or already known.

The complete public EPSS and CISA KEV catalogs are downloaded separately. Your Rapid7 vulnerability report is matched against those datasets locally.

CVSS

How severe is it?

The Common Vulnerability Scoring System describes the technical severity of a vulnerability, generally on a 0–10 scale. Higher scores indicate greater potential technical impact.

CVSS severity does not by itself tell you whether attackers are currently exploiting the vulnerability or how likely exploitation is.

EPSS

How likely is exploitation?

The Exploit Prediction Scoring System (EPSS), maintained by FIRST, estimates the probability that a published CVE will be exploited in the wild during the next 30 days.

Example: EPSS 72% indicates substantially stronger predicted exploitation activity than EPSS 0.1%.

Percentile shows how a CVE's EPSS score ranks relative to other scored vulnerabilities.

KEV

Is exploitation already known?

CISA's Known Exploited Vulnerabilities catalog identifies vulnerabilities for which there is evidence of exploitation in the wild.

VulnPrioritizer highlights KEV matches separately because known exploitation is a different signal from technical severity or predicted exploitation probability.

Why combine the signals?

Data handling & privacy

Rapid7 data remains local. Uploaded Rapid7 CSV files are processed by VulnPrioritizer and are not transmitted to FIRST or CISA.

Analysis sessions are temporary. Processed Rapid7 information is retained only in temporary container storage so all application workers can support navigation between Dashboard, CVE Investigation, and Asset Investigation. This temporary storage is not mapped to the persistent threat-intelligence volume; sessions disappear when the container is recreated and older sessions may be discarded as new analyses are created.

VulnPrioritizer downloads the complete public EPSS and CISA KEV datasets and performs CVE matching locally. The persistent Docker volume stores these public threat-intelligence datasets and update metadata; it does not intentionally store uploaded Rapid7 reports.
